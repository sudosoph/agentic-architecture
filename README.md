# Agentic Architect (`agenticarchitect.ai`)

Source repository for **[Agentic Architect](https://agenticarchitect.ai)**, authored by **Sophia Stein** in Boulder, CO.

Agentic Architect publishes vendor-neutral systems architecture essays, model and hardware benchmarks, university syllabi, and hands-on workflow courses inside **The Agentic Architect Lab**.

## Live Surfaces

- **Editorial Monograph:** [https://agenticarchitect.ai](https://agenticarchitect.ai)
- **Cornerstone Reference:** [What Is an Agentic Architect?](https://agenticarchitect.ai/what-is-an-agentic-architect)
- **Field Monograph (12 Chapters):** [The Sovereign Stack](https://agenticarchitect.ai/sovereign-stack)
- **Essays & Architecture Notes:** [https://agenticarchitect.ai/blog](https://agenticarchitect.ai/blog)
- **Courses & Skool Lab:** [https://agenticarchitect.ai/courses](https://agenticarchitect.ai/courses)
- **Open 20/80 Task Readiness Kit:** [https://agenticarchitect.ai/starter-kit](https://agenticarchitect.ai/starter-kit)
- **Substack Weekly Synthesis:** [https://agenticarchitectai.substack.com](https://agenticarchitectai.substack.com)

## Local Development & Verification

```bash
npm install
npm run dev           # Start local Next.js preview on http://localhost:3000
npm run qc            # Run automated Brand, Design & SEO quality gatekeeper
npm test              # Run full Vitest suite
npm run build         # Build Next.js + OpenNext Cloudflare Workers bundle
npm run seo:ping      # Submit canonical URLs to IndexNow search engines
```
