# Agentic Architect (`agenticarchitect.ai`)

Source repository for **[Agentic Architect](https://agenticarchitect.ai)**, authored by **Sophia Stein** in Boulder, CO.

Agentic Architect publishes practical, vendor-neutral AI workflow playbooks, portable Brand Brain kits (`voice.md` + `icp.md`), corporate training curricula, and sovereign AI infrastructure guides for founders, operators, and engineering leaders.

## Local Development & CLI Scripts

```bash
npm install
npm run dev           # Start local Next.js preview on http://localhost:3000
npm test              # Run Vitest suite
npm run build         # Build Next.js + OpenNext Cloudflare Workers bundle
npm run new:pack      # Scaffold an omnichannel content pack from a topic or slug
npm run substack:prep # Convert an MDX playbook into Substack ProseMirror JSON
npm run outreach:pack # Generate tailored 3-touch outreach drafts across 4 ICP segments
npm run seo:ping      # Submit canonical URLs to IndexNow search engines
```
