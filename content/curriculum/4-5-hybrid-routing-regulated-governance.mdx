## The Pragmatic Endgame: Hybrid Policy Routing

Almost no serious organization runs 100% public consumer cloud or 100% air-gapped local hardware. The highest-performing architecture in late 2026 is a **Policy-Aware Hybrid Router**:

```text
[Workflow Request + Data Tier Tag]
   ├── Tier = GREEN (Public web research, public copy)
   │      └──> Fast / Workhorse Cloud API (lowest cost per verified task)
   ├── Tier = AMBER (Internal SOPs, standard CRM/ERP ops)
   │      └──> Contractual ZDR Enterprise API or 3P VPC Gateway (Bedrock / Vertex)
   └── Tier = RED (Unredacted PHI, privileged M&A/contracts, core IP)
          └──> Private Tailscale / VPC Open-Weight Node (Zero external egress)
```

## Immutable Auditability Without Creating a Toxic Data Honeypot

Security and compliance committees (`HIPAA`, `SOC2 Type II`, `ISO 42001`, `EU AI Act`) need proof of governance without a central log database full of raw patient or client secrets. Log **cryptographic content hashes, schema classification tags, model/harness git SHA, token cost, binary verifier outcome, and the approving human's identity** so every automated and human-gated decision is 100% reconstructable during an audit.
