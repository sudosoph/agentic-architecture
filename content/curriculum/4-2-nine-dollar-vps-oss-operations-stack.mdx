## Owning Your Orchestration Spine for Under $10/Month

Before buying GPU hardware, reclaim control over your **workflow, scheduling, analytics, and state layer**. A single `4GB` to `8GB` Linux VPS (`Hetzner`, `DigitalOcean`, or your existing cloud VPC) comfortably runs:

- **`Caddy 2` (~30 MB RAM):** Automatic Let's Encrypt TLS termination and clean reverse-proxy headers.
- **`Postgres 16` + `pgvector` (~400 MB RAM):** Shared transactional state, idempotency ledger, and semantic memory store bound strictly to an internal Docker bridge network.
- **`n8n` Community / Queue Mode (~450 MB RAM):** Visual webhook and cron orchestrator calling your direct APIs and staging human-approved drafts.
- **`Umami` (~200 MB RAM) + `Uptime Kuma` (~80 MB RAM):** Cookie-free privacy analytics and instant webhook/email health alerts when any workflow or endpoint degrades.

## Non-Negotiable Production Hardening Checklist

1. Disable password SSH authentication; allow Ed25519 keys or Tailscale SSH only.
2. Remember Docker bypasses standard `ufw` chains if you publish `-p 5432:5432`; bind internal ports exclusively to `127.0.0.1` or internal Docker networks.
3. Run nightly `pg_dump` -> `restic` encrypted snapshots to object storage and test a full restore into a scratch container once a month.
