@AGENTS.md

## Repository Overview

Source code for `https://agenticarchitect.ai` (Next.js 16 + Tailwind CSS v4 OKLCH + OpenNext on Cloudflare Workers).

Before authoring or editing any essay, component, page, or social pack, read `.agents/skills/editorial-and-site-qc/SKILL.md` and run `npm run qc && npm test`.

## BSW Workshop Archive (`content/bsw/`)

Committed materials from the Boulder Startup Week hands-on workflow lab live in `content/bsw/` and `public/slides/bsw26.html`:
- `content/bsw/tutorial.md`: 17-step build-along guide
- `content/bsw/setup.md`: provider swap-in recipes (Groq, Jina, Ollama, OpenRouter)
- `content/bsw/handouts/`: printable 20/80 worksheet, operating rules, qualification criteria, JSON schemas, and OSS growth playbook
